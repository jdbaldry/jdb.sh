The power of literate programming is not that the code and documentation coexist in a file,
it's actually that you can structure the file in the most natural way for documentation and then tangle the code from that.

** Set reasonable default options

From [[https://pubs.opengroup.org/onlinepubs/9799919799/utilities/V3_chap02.html#tag_19_26][2.15 Special Built-In Utilities]].

*** Exit early
#+begin_quote
When this option is on, when any command fails (for any of the reasons listed in [[https://pubs.opengroup.org/onlinepubs/9799919799/utilities/V3_chap02.html#tag_19_08_01][2.8.1 Consequences of Shell Errors]] or by returning an [[https://pubs.opengroup.org/onlinepubs/9799919799/utilities/V3_chap02.html#exit][exit]] status greater than zero), the shell immediately shall exit, as if by executing the exit special built-in utility with no arguments
#+end_quote

#+name: errexit
#+begin_src sh
  set -e
#+end_src

*** Disable pathname expansion
#+begin_quote
The shell shall disable pathname expansion.
#+end_quote

#+name: noglob
#+begin_src sh
  set -f
#+end_src

*** Warn about unset variables
#+begin_quote
When the shell tries to expand, in a parameter expansion or an arithmetic expansion, an unset parameter other than the '@' and '*' special parameters, it shall write a message to standard error and the expansion shall fail with the consequences specified in [[https://pubs.opengroup.org/onlinepubs/007904875/utilities/xcu_chap02.html#tag_02_08_01][2.8.1 Consequences of Shell Errors]].
#+end_quote

#+name: nounset
#+begin_src sh
  set -u
#+end_src

** Add usage

  usage() {
    cat <<EOF
  Justify the expense of a .sh domain by presenting my site as a POSIX shell script.
  I guess it may as well list the pages.

  Usage:
    ./jdb.sh

  Examples:
    ./jdb.sh
  EOF
  }

** Support the ~--help~ option

Surely this is the most common mechanism of command line tool discovery.

#+name: help
#+begin_src sh
  case "$1" in
    -h|--help)
      usage

      exit 0
      ;;
    ,*)
      printf "Unknown option: %s\n" "$1" >&2
      usage

      exit 1
      ;;
  esac
#+end_src
